## 📌 Descripción del Portafolio

Este repositorio contiene las evidencias de aprendizaje, actividades prácticas y proyectos desarrollados durante el ciclo académico. Está enfocado en afianzar los conceptos fundamentales del modelado de datos y el diseño relacional de bases de datos.

En este portafolio se documenta el avance progresivo en:
* Fundamentos teóricos sobre bases de datos relacionales.
* Diseño de Diagramas Entidad-Relación (E-R).
* Mapeo y conversión al Modelo Relacional (identificación de PKs, FKs y cardinalidades).
* Creación de las primeras tablas en SQL mediante sentencias DDL y manipulación de datos con DML.

---

## 📑 Estructura del Repositorio

* **`/diagramas`**: Archivos de diseño conceptual (Diagramas E-R) y lógico (Modelo Relacional) en formato `.drawio` y exportaciones visuales.
* **`/scripts-sql`**: Archivos `.sql` organizados con sentencias DDL (`CREATE TABLE`, llaves primarias, foráneas y restricciones de integridad) y DML (`INSERT`, `SELECT` básicos).
* **`/apuntes`**: Documentación de las prácticas realizadas en clase.

## 🎯 Objetivos de Aprendizaje

1. **Modelado Conceptual y Lógico:** Comprender y aplicar las reglas de negocio para identificar entidades, atributos y relaciones construyendo diagramas E-R y esquemas relacionales normalizados.
2. **Implementación en SQL:** Escribir scripts de creación de estructuras físicas en MySQL, aplicando correctamente restricciones de integridad (`PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `CHECK`, `UNIQUE`) y ejecutando consultas básicas.
